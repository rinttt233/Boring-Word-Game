# 技术线路实施蓝图（多阶段）

> 现实工业史推进：电气化 → 基本石化 → 稀有金属 → 稀土催化 → 电子学(延展)。
> 全部机制复用现有数据驱动框架（substances/facilities/recipes/recovery/regions + 可选/依赖），
> 不修改引擎。关键现实耦合保持硬约束。
> 终局关系：暂不定（数据库仍为磁存储终局；阶段5先作通关后可选深水区）。
> 催化剂机制：= 设施升级配方（同输入更高产出/更低能耗）。

## 阶段 0 · 现状 ✅
煤焦化→高炉→钢→硫酸/氨→氯碱/炸药/初级裂解（二战化工）。

## 阶段 0·副产物与发电体系（TL-0 前置批）★
> 定稿机制（方案C）：通用燃料热值 + 燃烧发电（burner 类）+ 每燃料独立效率。
> 副产物体系从现有阶段0补起，随各阶段扩展；发电方式合理演进不贪多。

### 机制设计（引擎扩展点）
1. **物质表加字段**：`heat_value`(MJ/kg) 标可燃物；缺失=不可燃。另给燃料标 `category:"能源"`。
2. **新增设施类 `kind:"burner"`**：燃烧发电设施。输入任意带 heat_value 的物质，产出电 = 消耗量×热值×该燃料效率系数。引擎新增 burner 分支（~30行，向后兼容，旧 def 无影响）。
3. **每燃料独立效率系数**：可配（煤气发电效率55% / 重油40%），支持精细分级。
4. **与现有燃煤电站并存**：保留现有 power_plant（固定配方设施），burner 类作多燃料电站，零迁移。

### 副产物生态机制（定稿：全生态建模，与 TL-0 合并一批）
- **byproducts 引擎实现**：`_tick_recipe` 读配方 byproducts 表（物质id→比例系数），随主产物同步输出。
  recipes.json 已有 byproducts 字段占位（早期遗留），引擎从未实现 → 补实现即可（~10行，向后兼容）。
- **副产物三条去处**：①烧掉发电(burner) ②★升级为化工原料(煤焦油→苯/酚→塑料) ③回用(氢→加氢/合成氨)。
- **煤焦油升级线**：煤焦油 → 苯/酚 → 酚醛树脂/塑料（阶段2聚合釜的原料源之一，跨阶段耦合）。
- **氯碱氢气**：高热值+化工原料双价值（现实必产，建模最典型）。
- 高价值副产物(煤焦油/氢)有深加工去路，低价值(高炉煤气)走发电，自然分层。

### 价值分层引导（热值数据示意）
焦炉煤气~18 / 煤24 / 焦炭30 / 渣油41 / 汽油44——渣油烧电划算(废物利用高)，把煤留着炼焦比烧了值(机会成本)。非白名单禁烧，靠热值+机会成本自然引导。

## 阶段 1 · 电气化时代 (~1900s)
- 新物质：copper(精铜), bauxite(铝土矿), aluminum(铝), cable(电缆), magnet(磁体)
- 新设施：
  - copper_refiner 电解精炼槽：copper_ore+sulfuric_acid+电 → copper
  - aluminum_smelter 霍尔电解槽：bauxite+电(巨) → aluminum
  - generator_v2 发电机(可选?)：copper+steel → 电网效率加成
- 恢复条目：
  - db_copper_refine【主线】：解锁 copper_refiner
  - db_aluminum【可选，耗电巨大】：解锁 aluminum_smelter
  - db_grid 【可选】：解锁电网效率加成设施
- 勘探：regions 加 bauxite 矿源(圈2-3)
- 玩法：电解铝=电老虎→逼迫扩张电网；铜=电气化基础。

## 阶段 2 · 基本石化与合成材料 (~1920s-40s)
- 新物质：diesel, kerosene, fuel_oil(重油), bitumen(沥青), benzene, phenol, resin(酚醛), polyethyl(聚乙烯)
- 新设施：
  - distill_tower 常压蒸馏塔：petroleum → 汽油/煤油/柴油/重油
  - reformer 催化重整：重油/石油 → 苯/甲苯
  - polymer_plant 聚合釜：ethylene/苯酚+催化 → 聚乙烯/酚醛
- 恢复条目：
  - db_distill【主线】：解锁蒸馏塔
  - db_reform【可选】：解锁催化重整
  - db_polymer【可选】：解锁聚合釜（合成材料→绝缘/管道→解锁高压电气）
- 勘探：regions 补 petroleum 更广分布
- 玩法：燃料分级 + 首批塑料（解锁高压电气/管道升级）。

## 阶段 3 · 稀有金属与高级冶金 (~战后)
- 新物质：nickel, chrome, tungsten, stainless(不锈钢), superalloy(高温合金)
- 新设施：
  - ore_concentrator 选矿机
  - arc_furnace 电弧炉(需巨电)：镍/铬/钨+电 → 合金
  - alloy_plant 合金厂
- 恢复条目：
  - db_refractory【主线】：选矿+电弧炉
  - db_alloy【可选，依赖 db_refractory】：不锈钢/超合金
- 勘探：regions 加 nickel/chrome/tungsten 矿(圈3-4)
- 玩法：解锁"升级版合成氨塔"(高压容器更好的钢) → 合成氨低压高效化。

## 阶段 4 · 稀土与催化体系 (~1950s-60s) ★核心玩法增量
- 新物质：monazite(独居石), rare_concentrate, neodymium, lanthanum, cerium, catalyst_v(钒系), catalyst_pt(铂系)
- 新设施：
  - rare_mill 选矿
  - solvent_extractor 溶剂萃取分离线：rare_concentrate + sulfuric_acid + 溶剂(需石化) → 钕/镧/铈
  - catalyst_line 催化剂再生线：稀土/钒/铂 → catalyst_*
- 恢复条目：
  - db_rare_earth【主线，跨阶段依赖】：解锁分离线（需 db_distill 提供溶剂）
  - db_rare_catalyst【可选/主线？】：解锁催化剂升级配方
- 勘探：regions 加 monazite(圈4-5)
- 玩法：催化剂=**效率乘区**——升级配方"同输入更高产出/更低能耗"，改变瓶颈取舍。

## 阶段 5 · 电子学起点（延展，终局关系未定）
- 新物质：silicon(粗硅), tcs(三氯氢硅), polysilicon(高纯硅)
- 新设施：silicon_plant 西门子法提纯：silicon+HCl+电 → 高纯硅
- 恢复条目：db_silicon（深水区）
- 用途：若终局升级为硅基存储则成主线；否则为通关后可选目标。

## 催化机制（决策定稿：升级配方）
- 每个催化剂条目解锁某设施的 catalyst_v2 配方：inputs 相同或略降、outputs 更高。
- 催化剂本身不消耗（一次性解锁永久加成），但解锁成本高、依赖稀土/稀有矿。

## 实施批次建议
- 批次A：阶段1（电气化）——最小闭环验证框架扩展
- 批次B：阶段2（石化）——跨阶段依赖(distill→溶剂)骨架
- 批次C：阶段3（稀有金属）——电弧炉/合金+升级合成氨
- 批次D：阶段4（稀土催化）——分离线+催化剂升级配方(核心)
- 批次E：阶段5（电子学）——可选深水区
